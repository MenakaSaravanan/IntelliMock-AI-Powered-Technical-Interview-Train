# 🚀 AI Interview Trainer

> An intelligent, web-based mock interview platform built to help candidates practice and improve their technical interviewing skills through real-time, interactive conversations. Powered by Python (Flask) and IBM Watsonx.ai.

---

## 🌟 Features
* **Interactive Multi-Turn Interviews:** Simulates a professional technical interviewer, asking follow-up questions one by one.
* **Role-Based Customization:** Tailor the mock interview to specific job roles.
* **Enterprise AI Integration:** Powered by IBM Watsonx.ai (`mistralai/mistral-small-3-1-24b-instruct-2503`) for accurate and context-aware responses.
* **Clean UI:** Responsive web interface built with HTML, CSS, and JavaScript.

---

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** Python, Flask Framework
* **AI Model:** IBM Watsonx.ai SDK
